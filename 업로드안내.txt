저장소 : https://github.com/kimyebin726/ToolKIT

[올릴 파일]
1. index.html                    -> 저장소 루트에 덮어쓰기
2. assets 폴더 전체              -> 저장소 assets 폴더 (덮어쓰기)
   - hero-loop-mute.mp4   (헤더 배경 영상)
   - promo-pangi.mp4      (우하단 포팡이 영상 위젯)
   - pangi-turnaround.gif (캐릭터 소개 턴어라운드)
   - emo-motion.gif       (모션 이모티콘)
   - song-pangpang.mp3 / song-shine.mp3 (노래)

* 위 6개 파일은 용량 때문에 index.html 안에 넣지 않고
  assets 폴더에서 불러옵니다. 반드시 함께 올려주세요.


[방법]
1. https://github.com/kimyebin726/ToolKIT 접속
2. Add file -> Upload files
3. index.html 과 assets 폴더를 함께 드래그 (폴더 구조 유지)
4. Commit changes
5. 2~3분 뒤 배포 주소에서 Cmd+Shift+R 로 새로고침
